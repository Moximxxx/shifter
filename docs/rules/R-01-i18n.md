# R-01: i18n Required for All User-Facing Strings

> Group: Code Quality | Severity: Mandatory

## Rule

All user-facing strings MUST use `i18n.T("key")` with translations in both `en.json` and `zh.json`.

## Scope

- TUI views: **mandatory** — every text, help bar, title, label
- CLI output: **recommended** — error messages, help text, status output
- Log messages: **optional** — can remain in English

## How To

1. Add key to `pkg/i18n/locales/en.json`
2. Add Chinese translation to `pkg/i18n/locales/zh.json`
3. Use `i18n.T("your.key")` in Go code
4. For variables: `i18n.Tf("key", map[string]string{"var": value})`

## Verification

```bash
# Check all i18n keys exist in both files
python3 -c "
import json
for l in ['en','zh']:
    with open(f'pkg/i18n/locales/{l}.json') as f:
        d=json.load(f)
    print(f'{l}: {len(d)} keys')
"
```

## Incident Prevention

This rule was created after INC-2026-06-16-helpbar-duplication, where hardcoded key prefixes in Go code caused duplicate text in TUI help bars.
